# BottleneckIQ
### Emergency Department Bottleneck Detection System

**A healthcare analytics application designed to identify operational bottlenecks and support data-driven improvements in emergency department workflows.**

## Project Overview

Emergency departments operate in complex, time-sensitive environments where delays in patient flow can affect operational efficiency and healthcare delivery.

BottleneckIQ is a full-stack application developed to support the analysis of emergency department operational data and help identify potential bottlenecks in patient flow.

The system integrates a React frontend, Python FastAPI backend, and MySQL database to provide a centralized environment for data processing, visualization, and operational performance analysis.

## Project Objectives

- Support the identification of potential bottlenecks in emergency department workflows.
- Make operational performance data more accessible through a centralized application.
- Provide data-driven insights to support healthcare resource planning and process improvement.
- Demonstrate the integration of data analytics and full-stack application development in a healthcare setting.
